# Nguồn Markdown tham chiếu

Các file bên cạnh là bản trích xuất/chuẩn bị dữ liệu để tham chiếu và thí nghiệm. Chúng có thể chứa lỗi OCR, cấu trúc không đồng nhất hoặc nội dung lịch sử.

- Không xem đây là bản công bố chính thức hoặc nguồn duy nhất để tư vấn pháp lý.
- Không biên tập lại nội dung pháp lý bằng suy đoán; mọi chỉnh sửa thực chất cần provenance và người rà soát phù hợp.
- Pipeline request hiện không đọc trực tiếp thư mục này; nó dùng corpus chunk trong `data/chunks/` và kiểm tra source ID theo `data/law_status.json`.
- Xem [data README](../README.md) và [data card](../../docs/data_card.md) để hiểu vai trò dữ liệu.
