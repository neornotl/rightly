- Pilot là điểm xuất hiện nghĩa vụ quản trị dữ liệu thực sự.

**Bất đồng**
- Đánh giá embedding cache hơi cao. Với dữ liệu hiện tại là văn bản pháp luật công khai, đây chưa phải ưu tiên.

### Minimax-M3
**Đồng ý**
- Phân biệt rõ Impact và Likelihood để ưu tiên.
- Nhấn mạnh side-channel, prompt injection, PII bypass là hợp lý.

---

## 2) TỰ ĐÁNH GIÁ

Tôi cần **siết lại 3 điểm** từ nhận định trước:

1. **Prompt injection**: trước đây tôi xếp Medium. Sau khi xét voice-first + public link, nên nâng lên **Medium-High**.
2. **Secret management**: cần đưa vào nhóm ưu tiên đầu thay vì xem như vấn đề vận hành thứ cấp.
3. **PII scrubber**: không nên giả định regex đủ hiệu quả cho tiếng Việt; cần coi đây là biện pháp giảm thiểu một phần, không phải biện pháp bảo vệ chính.

### Top rủi ro theo giai đoạn

**LOCAL/MVP**
- Outbound transcript tới LLM cloud chứa PII (Cao / Trung bình).

**PUBLIC LINK**
- API key/secrets lộ qua cấu hình, traceback, debug (Cao / Trung bình).
- Prompt injection qua voice/ASR (Cao / Trung bình).
- Abuse/DDoS làm tăng chi phí API hoặc ngừng dịch vụ (Trung bình-Cao / Cao).
- Dữ liệu tạm thời trên host cloud, cache, session state (Trung bình / Trung bình).

**PILOT 8-10 NGƯỜI**
- Thu thập dữ liệu cá nhân nhưng consent chưa đủ rõ (Cao / Trung bình).
- Tái nhận dạng từ transcript đã "ẩn danh" (Cao / Trung bình).
- Gửi dữ liệu người thật sang Groq/Gemini không được giải thích minh bạch (Cao / Trung bình).

**NỘP HỒ SƠ / DEMO**
- Mang theo dữ liệu thật, logs, contacts, screenshots chứa PII (Cao / Thấp-Trung bình).
- Video demo vô tình lộ tên, SĐT, transcript thật (Cao / Trung bình).

### Ưu tiên giảm thiểu (ROI cao nhất)

**P0 (trước public link)**
1. Mặc định **redact PII trước mọi outbound LLM call**.
2. `SAVE_TRANSCRIPTS=false` mặc định.
3. Log rotation + auto-delete 7-30 ngày.
4. Tách `contacts.json` khỏi repo; inject từ secret/config.

**P1 (trước pilot)**

7. Dùng ID ngẫu nhiên thay cho tên thật.
8. Kiểm thử prompt injection và ASR abuse.
9. Rate limiting + quota theo IP/session.

**P2 (trước nộp hồ sơ)**
10. Data minimization review.
11. Xóa toàn bộ dữ liệu pilot không cần thiết.
